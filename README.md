# Tascovant Data — developer pilot

Tascovant provides source-attributed ECB currency reference data, batch conversions, accumulated historical observations and freshness reports for software agents. Free sandbox; no payments. Reference rates are not executable trading prices.

## Try it
```sh
curl --fail https://agent-nexus-data.c-shepard.workers.dev/v1/sample
```

[API specification](https://agent-nexus-data.c-shepard.workers.dev/openapi.json) · [Apply for pilot](https://agent-nexus-data.c-shepard.workers.dev/apply) · [Pilot portal](https://agent-nexus-data.c-shepard.workers.dev/pilot)

Full sandbox access requires owner approval. Keep your application ID and share it privately through your existing contact channel with the owner. Do not post API credentials or invitation codes. Historical coverage is limited to accumulated observations.

The included Postman collection contains only public GET requests and no credentials.
